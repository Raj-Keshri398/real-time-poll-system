# Real-Time Live Poll System (Laravel)

## Features
- Login / Register
- View Active Polls
- One Vote Per IP
- Admin IP Release
- Live Results (AJAX)

## Tech Stack
- Laravel
- PHP
- MySQL
- jQuery
- Bootstrap

## Setup
1. composer install
2. cp .env.example .env
3. php artisan key:generate
4. php artisan migrate
5. php artisan serve

## URL
http://127.0.0.1:8000/polls
